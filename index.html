Own · RAG · LLM · full-stack

ZUPdeCO AI Assistant

A standalone assistant API with a Next.js chat UI: users upload documents, the backend splits and embeds them, PostgreSQL stores chunks, and retrieval feeds Google Gemini. The same NestJS service can sit beside an Ednov tutoring API as a copilot.

  • LangChain text splitting and Gemini chat
  • Cosine retrieval over chunk embeddings stored as JSON in Postgres — not pgvector
  • Prisma models for conversations, documents, benchmarks, and evaluation jobs
  • Standalone Next.js UI includes chat, documents, benchmark, and settings routes
